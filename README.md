# Stillness releases

This repository holds only the Stillness installers and the automatic update feeds. It contains no source code.

- Downloads: https://github.com/createrman343212/stillness-releases/releases
- Windows releases are tagged `windows-vX.Y.Z`, macOS releases `macos-vX.Y.Z`.
- If Windows SmartScreen warns you, choose "More info → Run anyway" (the installer is not code-signed yet).
